# Action Video Factory — Script Breakdown (대본 → 줄콘티)

대본 텍스트를 받아 파이프라인이 처리할 수 있는 표준 줄콘티로 변환한다.
이 스킬은 포맷을 정규화하는 역할이고, 창작적 판단은 하지 않는다.
창작적 판단은 다음 단계인 `action-video-factory-concept`이 한다.

`../../references/action-video-foundations.md`를 로드한다.

---

## 언제 사용하나

- 대본(복붙 텍스트)이 있고 콘티 작업을 시작할 때
- 파이프라인 0단계 — 항상 이 스킬이 먼저

## 입력 형태

어떤 형식이든 처리한다:
- 한국어 드라마/영화 대본 (씬 번호, S#, 씬헤딩 등)
- 영어 대본 (INT./EXT. 헤딩)
- 혼용 대본
- 헤딩 없이 서술형으로 쓴 대본
- 웹툰/소설을 대본처럼 정리한 텍스트

헤딩이 없거나 포맷이 불규칙해도 문맥으로 씬 경계를 추론한다.

---

## 처리 과정

### 1단계 — 씬 경계 파악

다음 신호로 씬 경계를 찾는다:
- 씬 번호 (S#1, #1, 씬1, Scene 1, INT./EXT.)
- 장소 변경
- 시간 경과 표시 (다음날, 그날 밤, 잠시 후 등)
- 인물 구성 변화 (새 인물 등장 또는 장소 분리)

경계가 불명확하면 드라마 단위로 묶는다 — 하나의 감정 흐름이 완결되는 단위.

### 2단계 — 씬별 핵심 요소 추출

각 씬에서:

| 요소 | 추출 기준 |
|---|---|
| **장소** | 실내/실외, 구체적 공간명 |
| **시간대** | 낮/밤/새벽/실내 (조명 계획에 영향) |
| **등장인물** | 씬에 있는 모든 인물, 주도권 가진 인물 표시 |
| **핵심 액션** | 물리적으로 일어나는 일 (싸움, 이동, 오브젝트 조작 등) |
| **감정 비트** | 씬 시작 감정 상태 → 씬 끝 감정 상태 |
| **핵심 대사** | 씬의 의미를 결정하는 대사 1~2줄 (있으면) |
| **씬 기능** | 서사에서 하는 역할 (소개/전환/클라이맥스/여운/정보전달) |
| **예상 런타임** | 대사량·액션량 기준 추정 (짧음 ~30초 / 보통 30초~2분 / 긺 2분+) |

### 3단계 — 씬 유형 분류

`action-video-foundations.md`의 씬 유형으로 분류:
- 격투/액션 시퀀스
- 감정씬 (대화 중심 감정 교환)
- 추격 시퀀스
- 대치/심문
- 몽타주
- 설명/전환 (짧은 브릿지)

## 출력 포맷 — 00_LineScript.md

```markdown
# 줄콘티 — [작품명 또는 "대본 분해"]
총 씬 수: N | 총 예상 런타임: X분

---

## 씬 [번호] — [씬 제목/한 줄 요약]

| 항목 | 내용 |
|---|---|
| **장소** | 실내 / [구체적 공간] |
| **시간대** | 낮 / 밤 / 새벽 등 |
| **등장인물** | A(주도), B |
| **씬 유형** | 격투 / 감정씬 / 추격 / 대치 / 몽타주 |
| **씬 기능** | 클라이맥스 / 전환 / 소개 등 |
| **예상 런타임** | ~45초 |

**감정 곡선:**
시작: [감정 상태]
전환점: [무슨 일이 일어나 감정이 바뀌는가]
끝: [감정 상태]

**핵심 액션:**
- [물리적으로 일어나는 일 1]
- [물리적으로 일어나는 일 2]

**핵심 대사 (있으면):**
> "[씬을 결정짓는 대사]" — ۬��물명]

**콘셉트 진입 메모:**
[다음 단계(concept)를 위한 메모. 이 씬에서 가장 중요하게 봐야 할 것, 제약, 특이사항]

---

## 씬 [다음] — ...
```

---

## 처리 원칙

- **창작하지 않는다.** 대본에 없는 것을 추가하지 않는다. 해석은 최소화.
- **모호하면 원문 그대로.** "슬픈 듯한 표정"을 "슬픔"으로 단정짓지 않는다.
- **씬 분량 조절.** 대본이 길면 씬을 합치거나 나누는 것을 제안한다 (결정은 사용자가).
- **핵심 대사는 원문 유지.** 요약하거나 의역하지 않는다.

---

## 예시

**입력 (대본 텍스트)**:
```
S#7. 옥상 - 밤

빗속에 서 있는 준혁. 뒤에서 다가오는 민서.

민서: 왜 전화 안 받았어.
준혁: (돌아보지 않고) 할 말이 없었어.
민서가 준혁의 어깨를 잡아 돌린다. 두 사람, 처음으로 눈이 마주친다.
민서: 그러면 안 되잖아.
준혁, 아무 말 못 하고 시선을 피한다.
```

**출력 (줄콘티)**:
```markdown
## 씬 7 — 옥상 대면

| 항목 | 내용 |
|---|---|
| **장소** | 실외 / 옥상 |
| **시간대** | 밤, 비 |
| **등장인물** | 민서(주도), 준혁 |
| **씬 유형** | 감정씬 |
| **씬 기능** | 전환점 (두 인물의 첫 직접 대면) |
| **예상 런타임** | ~30초 |

**감정 곡선:**
시작: 준혁 회피, 민서 추격·불안
전환점: 민서가 준혁을 돌려 눈이 마주침
끝: 준혁 무너짐, 민서 기다림

**핵심 액션:**
- 민서가 준혁 어깨를 잡아 돌림
- 두 사람 처음으로 눈 마주침
- 준혁이 시선을 피함

**핵심 대사:**
> "그러면 안 되잖아." — 민서

**콘셉트 진입 메모:**
비와 야간이 핵심 분위기 요소. 시선의 회피와 마주침이 씬의 의미. 대사보다 신체 언어가 중심.
```
