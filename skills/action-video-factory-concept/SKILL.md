# Action Video Factory — Concept (방향성 기획)

이 스킬의 역할은 **발산**이다. 하나의 줄콘티를 5가지 색깔이 다른 선택지로 분화시킨다.
"비슷한 분위기의 5가지 버전"이 아니라 **영화적 언어가 근본적으로 다른 5개의 베팅**이어야 한다.

`../../references/action-video-foundations.md`와 `../../references/action-filmmaker-library.md`를 시작 시 로드한다.

---

## 언제 사용하나

- 줄콘티가 있고 어떤 영화 언어로 찍을지 결정이 필요할 때
- "이 씬을 어떻게 찍을까"라는 질문에서 시작할 때
- 기존 방향이 안 먹혀서 새로운 각도가 필요할 때

## 먼저 확인할 4가지

줄콘티에서 대부분 파악 가능하지만, 불분명하면 확인:

1. **씬의 기능** — 이 씬이 전체 서사에서 하는 역할 (반전, 클라이맥스, 소개, 전환)
2. **감정 곡선** — 씬 시작과 끝의 감정 상태 변화
3. **핵심 비트** — 반드시 전달해야 하는 정보나 감정 1개
4. **제약** — 로케이션, 배우 수, 예산 (실현 가능성에 영향)

---

## 좋은 콘셉트의 구조

**3~5개가 서로 불일치해야** 한다. 강제로 스펙트럼을 만든다:

- **직선 (Safe)**: 숙련된 팀이 기본적으로 선택할 방향. 기준선. 때로는 정답.
- **카메라 주도 (Camera-led)**: 특정 무빙이나 앵글이 씬의 의미를 만드는 버전.
- **배우 주도 (Actor-led)**: 카메라가 뒤로 빠지고 배우의 반응이 전부인 버전.
- **거장 기법 (Style-led)**: 특정 STYLE 프리셋을 핵심으로 씬을 재해석.
- **스트레치 (Stretch)**: 방이 기울어지는 아이디어. 리스크 있지만 다른 것들을 끌어올림.

각 콘셉트는 Higgsfield 실현 가능성을 솔직하게 평가한다.
모델은 이미지-투-비디오이고, 정밀한 안무·텍스트·실존 인물 likeness에는 약하다.

---

## 출력 포맷

`10_Concepts.md` 작성:

```markdown
# 콘셉트 방향성 — [씬 제목]
입력 줄콘티: [한 줄 요약]

---

## 콘셉트 N — [직관적 이름]

**전제.** 관객이 무엇을 보는가, 시작부터 끝까지 한두 문장.
**감정.** 처음 2초의 감정적 읽힘. 구체적으로.
**카메라 전략.** 주요 샷 언어, 무빙 선택, 앵글 결정.
**거장 레퍼런스.** 어떤 STYLE 프리셋을 쓸 것인가 (1~2개), 왜.
**레지스터.** foundations의 레지스터 중 하나 (사실주의-다큐 / 장르-액션 / 누아르-스릴러 / 감성-드라마 / 스타일리시-비주얼)
**Higgsfield 실현 가능성.** 쉬움 / 보통 / 어려움. 어려운 지점 1개와 해결책.
**레퍼런스 영화/씬.** 이 방향과 닮은 실제 작품.
```

마지막에 **추천 한 줄** — 어떤 것을 선택하겠는지, 왜. 중립적 메뉴가 아닌 의견.

## 예시

**예시 — 격투씬의 방향성 5개**

줄콘티: 복도에서 형사 A와 용의자 B의 1:1 격투. A가 결국 이긴다.

- *콘셉트 A — "피로의 물리학" (배우 주도, 롱테이크)*: 컷 없는 60초 격투. 두 배우의 체력 소진이 씬 자체. `PCW_LONG_TAKE_FIGHT`. 어려움 — kling 3.0의 싱글 테이크 한계 내에서 처리.
- *콘셉트 B — "공간이 무기다" (카메라 주도, 로케이션)*: 복도의 문·벽·모퉁이를 안무에 완전 통합. `RSW_LOCATION_LOCK`. 보통 — 로케이션 분석 후 키프레임 정확도 확보.
- *콘셉트 C — "임팩트 순간들" (편집 주도, 슬로우)*: 주요 타격 순간만 extreme slow. 나머지 실시간. `PHJ_SLOW_IMPACT`. 쉬움 — 각 슬로우 샷을 별도 kling 클립으로.
- *콘셉트 D — "냉정한 신의 시점" (앵글 주도, Bird's Eye)*: 격투 전체를 정수리에서 overhead로. 안무의 기하학적 아름다움. `DF_OVERHEAD_MASTER`. 어려움 — seedance 2.0 overhead 키프레임 정확도 테스트 필요.
- *콘셉트 E — "망가진 세계" (스트레치, Dutch)*: 격투 내내 Dutch angle. 공간 자체가 무너지는 느낌. `PCW_DUTCH_STILL` + `SPEC_DUTCH_ACTION`. 보통 — 프리셋 consistency 유지가 관건.

추천: B. 로케이션이 이미 있고, 공간 통합이 가장 오리지널한 선택이며 Higgsfield로 실현 가능성이 높다.

---

## 제약

- 하나의 아이디어를 색깔만 바꿔 5개로 만들지 않는다. 진짜 다른 영화적 선택이어야.
- 실현 가능성을 솔직히 평가한다 — 예쁜 콘셉트가 실행 불가면 신뢰만 깎인다.
- 선택된 콘셉트의 레지스터와 STYLE 프리셋은 `action-video-factory-storyboard`로 그대로 전달.
