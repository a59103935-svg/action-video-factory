# Action Video Factory — Storyboard (액션+감정 콘티 전용)

이 스킬은 brand loop나 웹 배경 영상이 아니라 **액션과 감정이 섞인 드라마틱 씬**을 위한 것이다.
`video-factory-storyboard`의 완전한 오버라이드 버전.

`../../references/action-video-foundations.md`  와 `../../references/action-filmmaker-library.md` 를 시작 시로드한다.

---

## 언제 사용하나

- 줄콘티가 있고 샷별 스토리보드가 필요할 때 (일반 경로, `action-video-factory-concept` 이후)
- 씬 설명만 있어도 OK — 줄콘티를 추론하고 진행
- 기존 스토리보드 수정 (타이밍, 샷 교체, 블로킹 변경)
- 로케이션 사진이 있을 때 — 공간 분석 후 블로킹에 통합

---

## 0. 로케이션 사진 분석 모듈

**로케이션 사진이 제공된 경우 먼저 이 단계를 실행한다.**

사진에서 다음을 분석하고 `20_Location_Analysis.md` 에 기록:

```
## 로케이션 분석 — [장소명]

### 공간 구조
- 전체 형태: [직사각형 복도 / L자 / 개방형 광장 / 다층 공간 등]
- 주요 구조물: [기둥, 계단, 출입구, 장벽, 가구 위치]
- 탈출/진입 경로: [최소 2개의 동선을 파악]
- 공간 깊이: [전경·중경·후경 분리 가능 여부]

### 자연광/인공광
- 주 광원: [위치, 방향, 강도]
- 부광원: [있다면 명시]
- 그림자 방향: [캐릭터 블로킹에 영향]
- 시간대 추정: [주광 / 역광 / 야간 / 실내조명]

### 카메라 포지션 제안
- A 포지션: [위치 + 샷 사이즈 + 앵글 + 활용 이유]
- B 포지션: [위치 + 샷 사이즈 + 앵글 + 활용 이유]
- C 포지션: [위치 + 샷 사이즈 + 앵글 + 활용 이유]
- 180도 축: [두 주요 포지션을 연결하는 축 방향]

### 블로킹 활용 요소
- 레이어링 포인트: [전·중·후경에 배치할 수 있는 구조물]

- 제약 사항: [촬영이 어려운 방향, 피해야 할 요소]

## 1. 줄콘티 해석

줄콘티(또는 씬 설명)에서 다음을 파악한다:

**드라마 구조**: 씬의 감정 곡선을 파악한다. 시작 상태 → 전환점 → 결말 상태.
가장 중요한 감정 비트 2~3개를 먼저 잡고, 샷 배치를 역산한다.

**액션 레이어**: 물리적 움직임의 안무. 누가 어디서 어떻게 움직이는가.
각 액션의 공간 논리를 검토 — 180도 룰을 지키면서 움직임이 연속적인가.

**정보 레이어**: 관객이 알아야 할 것을 언제, 어떻게 보여줄 것인가.
인서트 컷, ECU 타이밍을 미리 계획.

---

## 2. 샷 설계 원칙

### 씬 유형별 샷 배분

**격투/액션 시퀀스**:
- WS 또는 EWS로 공간 설정 (1~2샷)
- MS 또는 MLS로 전체 안무 파악 가능 (주샷)
- CU/ECU로 임팩트 순간, 감정 반응 (인서트)
- 슬로우모션 포인트는 절제 — 씬당 최대 1번
- 전형 예: `WS(설정) → MS(안무) → CU(임팩트) → MS(결과) → ECU(감정)`

**심문/대치 시퀀스**:
- 180도 룰 엄수. 축을 먼저 설정하고 모든 샷이 그 축의 같은 쪽
- OTS + CU 교환이 기본 리듬
- Dutch angle은 권력 불균형 표현에만 제한적 사용
- 전형 예: `WS(공간 설정) → MS(두 인물, 축 확인) → OTS A→B → CU A → CU B → ECU (결정 순간)`

**감정 폭발 시퀀스**:
- 폭발 전 — 긴 홀드, 얕은 심도로 내면 압박
- 폭발 순간 — 카메라가 반응 (줌인, 핸드헬드 흔들림)
- 폭발 후 — 여백 샷. 공간이 감정을 품도록
- 전형 예: `MCU(압박 축적) → CU(한계 순간) → ECU(폭발) → LS(여운)`

**추격 시퀀스**:
- 지리 명확성 최우선 — EWS로 공간 관계를 주기적으로 상기
- 스크린 디렉션 일관성 엄수
- 핸드헬드 + 스테디캠 전환으로 긴박감과 팔로잉 교차
- 전형 예: `WS(출발점 설정) → MS핸드헬드(추격자) → MS핸드헬드(피추격자) → EWS(거리 관계) → CU(반응) → WS(결말 공간)`

### 렌즈 선택 규칙

씬의 감정 목적에 따라 렌즈를 지정한다. 이유 없는 렌즈 변경 금지.

- 고립·압박 → 85mm~135mm (배경 압축, 주인공 고립)
- 에너지·혼돈 → 24mm 이하 (공간 왜곡, 역동성)
- 중립·일상 → 35~50mm
- 관찰·감시 → 100mm+ (인물이 모르게 포착하는 느낌)
- 장대함·스펙터클 → 아나모픽 + 광각

### STYLE 프리셋 배정

`action-filmmaker-library.md`에서 씬에 맞는 프리셋을 선택한다.

**배정 기준**:
1. 씬의 주된 감정/목적이 무엇인가
2. 어떤 거장의 기법이 그 감정을 가장 효과적으로 전달하는가
3. 이 씬의 예산/일정/로케이션에서 실제 구현 가능한가

**씬당 최대 2개**. 2개 선택 시 어떤 샷에 각각 배정되는지 명시.

## 3. 배우 블로킹/동선 기록

각 샷에서 배우의 물리적 위치와 움직임을 명시한다:

```
블로킹:
  A (이름): 프레임 왼쪽 1/3, 후경에서 등장 → 카메라 쪽 전진
  B (이름): 프레임 오른쪽, 정면, 정지
  시선: A→B (오른쪽으로), B→A (왼쪽으로) [180도 축 유지]
  공간 활용: 기둥을 A가 지나면서 차폐→노출 처리
```

로케이션 분석이 있는 경우 구조물과 블로킹을 연결한다:
`A는 로케이션 분석의 '동선 B'를 따라 기둥 A→기둥 B 방향으로 이동`

## 5. 키프레임-퍼스트 원칙

키프레임 스틸이 룩을 결정한다. 모션보다 키프레임이 먼저다.

**모델 라우팅**:
- 기본: `nano banana pro`
- 텍스트/라벨 포함: `chatgpt image 2`
- 실존 인물 likeness, 브랜드 로고: 생성 불가 → 포스트에서 합성

**키프레임 프롬프트 작성 원칙**:
- 정지 순간을 묘사한다. 움직임이 아니라 프레임.
- 7개 요소 반드시 포함: SUBJECT, SETTING, MOOD, LIGHT, COMPOSITION, LENS, PALETTE, NOT
- NOT 항목에는 반드시 foundations의 안티-클리셰 목록을 포함
- 로케이션 분석이 있다면 SETTING에 반드시 통합

---

## 6. 연속성 자동 체크

스토리보드 완성 후 아래 항목을 자동으로 검토하고 문제 발견 시 즉시 수정:

- [ ] 180도 룰 — 모든 대화씬에서 카메라가 축의 같은 쪽에 있는가
- [ ] 스크린 디렉션 — 추격+이동씬에서 방향이 일관적인가
- [ ] 매치 온 액션 — 컷 포인트가 액션 중간에 있는가 (시작/끝이 아닌)
- [ ] 아이라인 매치 — 시선 방향과 다음 샷의 대상이 일치하는가
- [ ] WS/EWS 설정 — 새로운 공간이 등장할 때 설정 샷이 있는가
- [ ] 샷 다양성 — 같은 샷 사이즈가 3개 이상 연속되지 않는가

## 예시

### 예시 1 — 격투씬 (좁은 복도, 1:1 대결)

**줄콘티**: 형사 A가 용의자 B를 복도에서 맞닥뜨린다. B가 먼저 공격. A가 벽을 이용해 역전.

**거장 시그니처**: `PCW_LONG_TAKE_FIGHT` (롱테이크로 피로와 물리성 강조), `RSW_LOCATION_LOCK` (복도 벽과 문을 격투에 통합)

**180도 축**: A(왼쪽)→B(오른쪽) 수평선. 카메라는 항상 남쪽.

```
샷 1-1 — EWS 복도 전경 (0:00–0:03)
  사이즈: WS | 앵글: Eye Level | 렌즈: 24mm | 무빙: Static
  블로킹: A가 복도 끝에서 등장, B가 중간에 등지고 서 있음
  키프레임: 좁고 긴 복도, 천장 형광등 한 줄, 두 실루엣 대칭 배치

샷 1-2 — MS 대면 (0:03–0:06)
  사이즈: MS | 앵글: Eye Level | 렌즈: 35mm | 무빙: Slow Push In
  블로킹: A 프레임 오른쪽, B 프레임 왼쪽 (OTS 없이 두 인물 모두 포함)
  키프레임: 두 인물 사이 공간, 긴장된 정지, 차가운 형광등

샷 1-3 — CU B의 주먹 (0:06–0:08, 슬로우)
  사이즈: CU | 앵글: Low Angle | 렌즈: 85mm | 무빙: Static
  STYLE: PHJ_SLOW_IMPACT
  블로킹: B의 주먹 클로즈업, 모션 블러 시작

샷 1-4 — MS 롱테이크 격투 시작 (0:08–0:22, 실시간)
  사이즈: MS | 앵글: Eye Level | 렌즈: 35mm | 무빙: Steadicam Follow
  STYLE: PCW_LONG_TAKE_FIGHT
  블로킹: A가 벽에 튕겨나며 반격 시작. 스테디캠이 둘을 모두 팔로우.
  연속성: 0:06 슬로우에서 실시간으로 스매시컷 전환
```

### 예시 2 — 감정씬 (이별 통보)

**줄콘티**: A가 B에게 "이제 끝이야"를 말한다. B는 처음에 믿지 않다가 현실을 직시.

**거장 시그니처**: `LCD_DOCUMENTARY_GAZE` (리액션을 기다리는 긴 테이크), `HJH_SHALLOW_LINGER` (심도 얕게 홀드)

```
