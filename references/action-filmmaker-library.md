# Action Filmmaker Library — 거장 기법 프리셋

거장별 시그니처 기법을 STYLE 프리셋으로 정의한 레퍼런스.
`action-video-factory-storyboard` 에서 씬당 1~2개 시그니처만 선택해 사용한다. 과잉 사용 금지.

---

## STYLE 프리셋 체계

프리셋 코드는 `[감독이니셜]_[기법명]` 형식.
스토리보드에 `STYLE: PTA_ONER` 처럼 명시한다.

---

## 액션 거장

### 박찬욱 (PCW)

| 코드 | 기법 | 설명 | 언제 쓰나 |
|---|---|---|---|
| `PCW_SYMMETRY` | 강박적 대칭 프레임 | 피사체를 정중앙 배치, 좌우 완전 대칭. 인물을 가두는 느낌. | 권력 구도, 고요한 위협, 심문 |
| `PCW_LONG_TAKE_FIGHT` | 롱테이크 격투 | 컷 없이 복도·공간을 가로지르는 격투. 지침·생존의 물리성 강조. | 피로한 전투, 실력 격차 표현 |
| `PCW_INSERT_MACRO` | 강조 인서트 컷 | 오브젝트 ECU → 장면 복귀. 정보와 긴장을 동시에 전달. | 무기, 손, 얼굴 디테일 |
| `PCW_DUTCH_STILL` | 틸팅된 정지화면 | Dutch angle + 정적 카메라. 왜곡된 세계관. | 캐릭터 내면 붕괴 직전 |

### 박훈정 (PHJ)

| 코드 | 기법 | 설명 | 언제 쓰나 |
|---|---|---|---|

| `PHJ_SLOW_IMPACT` | 슬로우 충격 순간 | 폭력의 순간만 extreme 슬로우. 나머지 실시간. | 결정적 타격, 총격 |
| `PHJ_CHAOS_HANDHELD` | 혼돈 핸드헬드 | 매우 불안정한 핸드헬드 + 빠른 줌. 혼돈·공포 극대화. | 군중 격투, 추격 |

### 류승완 (RSW)

| 코드 | 기법 | 설명 | 언제 쓰나 |
|---|---|---|---|
| `RSW_OVERHEAD_FIGHT` | 탑 뷰 격투 | 완전 수직 overhead shot으로 격투 안무 시각화. | 다대다 격투, 공간 지리 설명 |
| `RSW_LOCATION_LOCK` | 로케이션 활용 록인 | 특정 공간의 구조물(계단, 기둥, 창문)을 격투 안무에 완전 통합. | 좁은 공간 액션 |
| `RSW_MOMENTUM_CUT` | 모멘텀 컷 | 액션의 운동 에너지를 살려 절묘한 타이밍에 컷. Match-on-action 완성형. | 고속 추격, 타격 시퀀스 |

## 사용 원칙

1. **씬당 시그니처 1~2개 최대** — 거장 기법 과잉 사용은 산만함을 만든다.
2. **STYLE 코드 명시** — 스토리보드 패널에 반드시 `STYLE:` 태그로 표기.
3. **이유 설명** — 왜 이 기법이 이 씬에 맞는지 한 줄로 정당화.
4. **감정 우선** — 기법은 감정 전달의 도구. 기법 자체가 목적이 되지 않도록.
5. **로케이션 통합** — 거장 기법은 실제 공간과 결합될 때 가장 강력해진다.
