# Action Video Factory — 공유 기반 레퍼런스

모든 Action Video Factory 스킬의 공통 컨텍스트. 스킬에서 직접 설명하지 않고 이 문서를 인용한다.

---

## 파이프라인

```
줄콘티 → Concept → Storyboard → Direct → Generate → Ship
```

- **줄콘티 (Line Script)** — 씬별 행동/감정/대사를 단순화한 텍스트 콘티. 입력 재료.
- **Concept** — 줄콘티를 3~5개의 시각 방향성으로 발전. 어떤 영화적 언어로 찍을 것인가. `10_Concepts.md`.
- **Storyboard** — 선택된 콘셉트를 샷별로 분해. 샷 사이즈·앵글·렌즈·무빙·블로킹·STYLE 프리셋·키프레임 프롬프트. `20_Storyboard.md`.
- **Direct** — 전체 룩 잠금. 레지스터·페이싱·카메라 언어·빛·컬러·그레인. `30_Direction.md`.
- **Generate** — 키프레임 스틸 → 모션 프롬프트 → Higgsfield MCP 실행 → 클립. `40_Prompts.md` + 미디어.
- **Ship** — 최종 편집, 컬러, 웹 인코딩, 납품.

4개 핵심 스킬 (Concept, Storyboard, Direct, Generate)은 체인으로 동작한다: 각각 이전 아티팩트를 읽고 다음 아티팩트를 쓴다. 단독으로도 실행 가능.

## 영화 문법 기준 (inference-sh 기반)

### 샷 사이즈 (Shot Size)

| 약어 | 명칭 | 프레이밍 | 주 용도 |
|---|---|---|---|
| ECU | Extreme Close-Up | 눈, 손가락 등 디테일만 | 극도의 감정, 결정적 디테일 |
| CU | Close-Up | 얼굴 가득 | 감정, 반응, 대화 |
| MCU | Medium Close-Up | 머리~어깨 | 인터뷰, 대화 |
| MS | Medium Shot | 허리 위 | 일반 대화, 액션 |
| MLS | Medium Long Shot | 무릎 위 | 걷기, 캐주얼 상호작용 |
| LS | Long Shot | 전신 | 캐릭터와 환경 관계 |
| WS | Wide Shot | 환경 주도 | 장소 설정, 규모 |
| EWS | Extreme Wide Shot | 광대한 풍경 | 장대함, 고립, 전환 |

### 카메라 앵글

| 앵글 | 효과 | 사용 시기 |
|---|---|---|
| Eye Level | 중립, 자연스러운 플레어 가득 | 감정, 차가운 축적 |
| High Angle | 때렜 피사체 작아보임, 취약함 | 약함, 개요 |
| Low Angle | 피사체 강해보임, 지배적 | 권위, 영웅, 위협 |
| Bird's Eye | 신의 시점, 지리적 개요 | 지도, 장소 설정 |
| Worm's Eye | 극단적 권력감, 경외 | 건축물, 거대한 존재 |
| Dutch Angle | 불안감, 방향감각 상실 | 긴장, 광기, 액션 |
| OTS (Over-the-Shoulder) | 캐릭터와 함께 배치 | 대화, POV |

### 카메라 무빙

| 무빙 | 설명 | 감정 |
|---|---|---|
| Pan | 삼각대에서 수평 회전 | 스캔, 팔로우, 공간 reveal |
| Tilt | 삼각대에서 수직 회전 | 높이 reveal, 권력 |
| Dolly | 피사체 향/반대로 이동 | 친밀감(인), 거리감(아웃) |
| Truck | 측면 이동 | 나란히 팔로우, reveal |
| Crane/Jib | 상하 수직 이동 | 장대한 reveal, 전환 |
| Zoom | 렌즈 초점거리 변경 | 극적 강조, 시점 이동 |
| Steadicam | 부드러운 핸드헬드 추적 | 몰입감, 팔로우 |
| Handheld | 의도적 흔들림 | 긴박함, 다큐 느낌, 혼돈 |
| Static | 고정 | 안정감, 관찰, 긴장 |

### 연속성 규칙

**180도 룰**: 두 캐릭터 사이의 가상의 선(축). 카메라는 반드시 이 선의 한쪽에만 머물러야 한다. 선을 넘으면 관객이 공간 관계를 혼동한다. 의도적으로 넘을 경우 중립 샷 또는 카메라 무빙으로 처리.

**매치 온 액션**: 동일 액션의 두 각도를 컷할 때 액션이 매끄럽게 이어져야 한다. (손이 문손잡이에 닿는 MS → 손잡이를 잡는 CU)

**아이라인 매치**: 캐릭터가 무언가를 볼 때, 다음 샷은 그것을 캐릭터의 시점에서 보여준다.

**스크린 디렉션**: 인물이 한 샷에서 왼→오른쪽으로 이동하면, 다음 샷에서도 같은 방향으로 이동해야 한다.

## 모델 라우팅 (Higgsfield)

기본값:
- **비디오**: `kling3_0` (액션/멀티샷 기본), `seedance_2_0` (분위기/배경/루프)
- **키프레임 스틸**: `nano banana pro` 기본, 텍스트·라벨 포함 시 `chatgpt image 2`
- **마케 히어로샷 에스컬레이션**: `cinematic_studio_3_0` 또는 `veo3_1`

액션씬 특이사항:
- 다중 샷 시퀀스 → `kling3_0` mode pro 우선
- 감정씬 (자연스러운 얼굴 반응) → `minimax_hailuo`
- 탐색 패스 → `veo3_1_lite` 720p로 먼저 확인 후 히어로 모델 투입

## 안티-클리셰 목록 (네거티브에 반드시 포함)

- 무의미한 슬로우모션 남발
- 도시 드론샷 (규모의 메타포)
- 파란 빛 AI 파티클·홀로그램

- 주인공이 폭발을 안 보고 걷는 씬
- 비로 치는 전투씬 (이유 없이)
- 편의점 CCTV 스타일 카메라
- 감정씬에서 과도한 클로즈업 스팸
- 배우 손/얼굴 워핑 아티팩트
- 배경 흔들림·왜곡

## 크레딧 원칙

실제 크레딧 = 실제 돈. 절대 방침:
- 크리에이티브 디렉션 사인오프 전에는 생성 금지
- 탐색은 `veo3_1_lite` / seedance `fast` 720p로
- 히어로 모델은 최종 픽 이후에만 투입
- 사운드 불필요 → `sound: off` (크레딧 절감)
- 배치 생성 전 `show_plans_and_credits` 확인
